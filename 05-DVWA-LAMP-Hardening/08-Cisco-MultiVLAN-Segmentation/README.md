# Cisco Networking: Multi-VLAN Segmentation, Router-on-a-Stick & Inter-VLAN ACLs

**Project Summary:** Multi-tier network simulation in Cisco Packet Tracer, 4 distinct VLANs (Admin, IT, HR, Guest), IEEE 802.1Q trunking with pruning on Fa0/24, Router-on-a-Stick on ISR4331 subinterfaces, and extended IP ACLs.
