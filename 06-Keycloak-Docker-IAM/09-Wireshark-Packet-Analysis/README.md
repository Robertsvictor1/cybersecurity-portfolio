**Project Summary:** Packet capture and deep packet analysis in Wireshark 4.6.4, Berkeley Packet Filters (BPF host 10.0.0.114), multi-layer protocol dissection (L2-L7), and extraction of plaintext HTTP POST credentials and CSRF tokens.
